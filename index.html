Price lists, discount rules, and the full Node / Network / EMS configurators — all running client-side. Nothing you enter here is uploaded or stored on a server.

No database, no accounts. This is a static, client-side version of the Actelis Price/Quote Tool. Pricing and discount data is bundled into the site as JSON files and all calculations run in your browser. No customer information, quotes, or configurations are ever sent to a server — anything you want to keep (a quote export or a saved wizard template) is saved to a file you download or to this browser's local storage on this device only.

What's included

Price & discount engine

Full price list (A/B/C items) and Type-D services/warranty list, with the region × customer-type discount matrix and NA deal-registration bonus.

Configurator wizards

Node Configurator (single-link chassis/standalone BOM math), Network/Repeater Configurator (multi-hop, PFU/repeater, dual-PFU feeding), and the EMS Licensing Wizard (site license tiers, redundancy, clients, add-ons).

Quote & export

Multi-site BOM builder, services/warranty lines, tax-inclusive totals matching the original report logic, printable PDF view, and CSV/Excel export.

What's different from the desktop tool

This online version has no customer database — there's no login and no saved customer records. Instead you simply pick a customer type (Reseller or End Customer) and region when building a quote, and the standard discount matrix is applied. Per-customer negotiated discount overrides, RMA quotes, the COGS/margin viewer, and the HubSpot export are intentionally out of scope for the public online tool. See the README in this site's repository for the full list of differences.
